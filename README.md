# Посмотри в окно

Учебный проект по вёрстке. На странице можно найти видео по городу и времени суток, выбрать ролик из списка и подгрузить дополнительные карточки.

## Запуск

Скачайте репозиторий и откройте `index.html` в браузере. Для загрузки видео нужен интернет.

https://github.com/dar5win/posmotri-v-okno-ad
